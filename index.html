✉ Conectar Gmail

Conecta tu cuenta de Gmail directamente para traer tus facturas. Necesitas un Client ID de Google (una sola vez) — usa "⚙ Configurar" si aún no lo tienes.

Configuración de conexión (una sola vez)

1. Ve a console.cloud.google.com → crea un proyecto.
2. Habilita la Gmail API (APIs y servicios → Biblioteca → busca "Gmail API" → Habilitar).
3. Configura la pantalla de consentimiento OAuth (tipo Externo), agrega el permiso gmail.readonly y agrégate a ti mismo como usuario de prueba.
4. Crea credenciales → ID de cliente de OAuth → tipo "Aplicación web". En "Orígenes de JavaScript autorizados" agrega la dirección desde donde abrirás esta app (ej: http://localhost:8000 si la sirves localmente, o el dominio si la subes a GitHub Pages / Netlify).
5. Copia el Client ID (termina en .apps.googleusercontent.com) y pégalo abajo.
Importante: esto no funciona abriendo el archivo con doble clic (file://) — Google exige http/https. Sirve la carpeta con algo como python3 -m http.server 8000 y abre http://localhost:8000/libro-de-facturas.html.
